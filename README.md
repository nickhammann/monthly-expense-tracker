# Monthly Expense Tracker

A simple personal finance web application for tracking recurring costs and one-time expenses.

The main goal of the project is to answer one simple question:

> **How much does my life currently cost per month?**

The application focuses on clarity and simplicity instead of trying to replicate a full banking or budgeting platform.

---

## Features

### Recurring Costs

Track regular expenses such as:

- Rent
- Internet
- Phone contracts
- Insurance
- Subscriptions
- Memberships

Each recurring cost can have its own billing interval:

- Monthly
- Quarterly
- Every 6 months
- Yearly

The application automatically calculates the average monthly cost.

Example:

```text
Car Insurance
€720 / year

Monthly average:
